❓ How to Play ElementSpeller

🧪
Every day features a secret word from the dictionary that can be perfectly spelled using chemical element symbols from the Periodic Table.
⚛️
Enter the chemical elements in order from left to right. You can type the full element name (e.g. Barium, Carbon, Iron) or its chemical symbol.
Example for BACON:
BaBarium CCarbon OOxygen NNitrogen
(Or Boron [B] + Actinium [Ac] + Oxygen [O] + Nitrogen [N])
❤️
Watch your strikes! You have 5 strikes allowed. If you guess an element that doesn't match the next letters, you lose a heart.
📅
A new puzzle is released every day at midnight UTC! Past daily puzzles can be played anytime in the Archive.
